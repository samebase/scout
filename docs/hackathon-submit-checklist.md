## While the video renders

- [ ] Open the signed-in submission form and confirm its actual required fields and questions.
- [ ] Prepare the listing: **TrailScout**, tagline, description, app link, team/contact details,
      and answers to the form's questions. Use the existing draft; keep the About page synchronized
      when changing shared copy.
- [ ] Select a main screenshot of the finished app and any useful extra images requested by the form.
- [ ] Confirm Luma registration is complete.
- [ ] Prepare the build announcement for X or LinkedIn, tagging Convex, OpenAI, Firecrawl,
      and AgentMail. Publish it and save its link.
- [ ] Make the [GitHub repository](https://github.com/samebase/scout) public when the release is ready.
- [ ] Check judge access while signed out: the live app, demo review, walkthrough,
      screenshots, and replay. Confirm how judges can start a task if sign-in or approval is needed.

## When the video is ready

- [ ] Watch the final export: audio, captions, camera placement, speed transitions, and duration.
- [ ] Upload to YouTube with a link judges can watch; check that processing has finished and the
      video plays while signed out. Add the retimed subtitle file if useful.
- [ ] Add final video and announcement links to the submission draft and About page. Refresh
      `hackathon.md` at the repository root with the final app and demo links.
- [ ] Fill the Vibe Apps form, verify every link, and submit before the deadline.
- [ ] Save the submitted entry URL and check that it appears in the hackathon entries.
