# Scout submission draft

Working copy for discussion. This file has not been submitted or published as a hackathon entry.

## Short description

Scout sends AI agents to try web products and show what happened through walkthroughs,
screenshots, and browser replays. Public reviews make the findings useful to anyone
considering the same product.

## Product description

Every website has a pitch. Finding out whether it does what you need often means
creating an account, learning the interface, and trying the product yourself.

Give Scout a website and something to try. An AI agent opens a browser, uses the
product, and records what happened. You can follow the visit as it happens or come
back to a walkthrough, screenshots, and a replay. The result shows what worked,
what failed, and what Scout could not finish.

Each Scout has its own identity, email inbox, browser profile, and service accounts.
It can sign up for a product, read verification emails, and return later using the
same accounts. That lets a review continue beyond the landing page into the product.

Reviews are public by default, with a private option. Someone else can open a review,
inspect the steps, and use those findings before spending time on the same question.
The public collection also shows products in use and makes their claims checkable.

A review records a particular attempt. Sites change, and an agent can get stuck or
miss something. Scout keeps the evidence available so readers can judge the result.

## Agreed homepage copy

Check if a product does what you need.

1. Send an AI agent to try a website for you.
2. See what happened in a walkthrough, screenshots, and a replay.
3. Public reviews make product claims checkable.

Example buttons begin with “Does signup work?” and “Review a hackathon entry.”
The third example is undecided. The existing review list remains the way to browse
results and open full walkthroughs; no featured-review section is planned.
